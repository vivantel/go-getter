- `routing/policy.mjs` chooses in the order the guardrails fix: models of a tier that the host runs and the data class allows (`eligibility.mjs`) come first; among them each delegation target is priced by `routing/cost.mjs`; escalation moves one tier up the ladder (cheapest eligible model per tier) and ends at a human after `go-getter.max-escalations` or when no stronger eligible tier exists. A project without governance adopted treats every model as eligible; with it, steps are `internal` data unless `--data-class` says otherwise.
- **Cost** of a step is `turns` model calls (default 6, 1,500 new input and 800 output tokens each): the prefix is read from the cache on every call but the first, which pays the cache read rate when warm and the 5-minute or 1-hour write rate when cold (plain input where the price fact lists no write price), plus input and output at list price, plus failure probability × the next tier's delegated cost, recursively to the bound. A delegate starts cold with only a handoff prefix (default 4,000 tokens plus the brief); staying in the session reads the whole session prefix warm. Failure rates (small 0.3, medium 0.15, large 0.05) and the step shape are defaults; an active decision carrying `go-getter.routing-calibration` (`failure-rates`, `step`) replaces them.
- **Tiers and hosts** come from fact 0024. Start tiers and efforts per task class come from the adopted `routing-start-tiers` and `routing-efforts` decisions; fast/strong and per-role classes group task classes, and a group starts at its strongest member.
- `apply` writes each role's compiled default (cheapest eligible model of its start tier, class effort) into the agent file where the host has per-agent model (`model`; `effort` where the manifest has it): Claude Code `model`/`effort`, Codex `model`/`model_reasoning_effort`, Kilo and OpenCode `model: <provider>/<model>`, Cursor `model: <id>[effort=<level>]`, Gemini CLI `model`. Copilot gets none (fact 0024). On Claude Code `apply` also writes `promptCacheTtl` and `subagentPromptCacheTtl` into `.claude/settings.json` unless the answer is host defaults.
- The pre-tool hook (`routing/delegate.mjs`) routes a call to the host's delegation tool (`Agent` on Claude Code, `spawn_agent` on Codex, `Task` on Cursor) whose `subagent_type` is a role of the roster: it sets `model` in the tool input, unless the delegator set one, to the value the manifest's `routing.delegation.models` table gives (Claude Code: the family alias `fable`, `opus`, `sonnet` or `haiku`, the only values its Agent tool accepts, observed 2026-10-05; the alias runs the family's current model, which may not be the priced one; hosts without a table get the full id); a model with no value is not rewritten, so the agent file's compiled default applies (advisory, on stderr); or denies with a hand-over reason when no eligible model exists, or does nothing when staying in the warm session is cheaper. Session prefix and warmth are estimated from the transcript file (size ÷ 4 tokens; last write against the main-session cache lifetime), and without a transcript the session is not a candidate. The delegation is auto-approved when rewritten (deny rules and path guardrails still run first).
- `go-getter route --class <c> [--context-tokens n --cache warm|cold --session-model id --data-class c]`, `--escalate --from <tier> --attempts <n>` and `--headless-flags --host <id>` give the orchestrating agent the same answers, with `delegateModel` the value the `--host` delegation tool accepts (its alias table, else the full id); routes are recorded as `event: route` with the expected cost in `cost` (an estimate, not a bill). Headless spend caps are not written by `apply`: `--headless-flags` prints `--max-budget-usd <n>` (Claude Code) or `--max-ai-credits <n>` (Copilot); other hosts have no headless cap.
- `go-getter routing calibrate [--min-samples n] [--dry-run]` (decision 0017) reads the telemetry log: a `route` record's outcome is the `verify:*` and `plan:done` records of its task class until the next route of that class (any failure fails it), giving failure rates per tier; records with input and output tokens give the step shape; gaps between records over the main-session cache lifetime are cold restarts, counted where one keep-alive read per lifetime would have cost less than the cold write. With at least 10 samples and a rate change of 0.05 or a shape change of 20 %, or 10 such gaps (then citing withdrawn decision 0074), it writes a `draft` decision `NNNN-routing-calibration` superseding the active one; it never activates it. Gaps are underestimated when sessions interleave, and token records arrive only with C.2.
- Not confirmed against vendor documentation: the `hookSpecificOutput.updatedInput` answer (with `permissionDecision: allow`) for Claude Code and Codex, and `updated_input` for Cursor; the delegation tool names `spawn_agent` and `Task`; that Codex `spawn_agent` takes a full model id in `model` (community reports only); that Cursor's `Task` runs a rewritten `model` (forum reports say some versions accept only `fast` there and ignore `updated_input`); the `<provider>/<model>` agent model format of Kilo and OpenCode; that `promptCacheTtl` and `subagentPromptCacheTtl` are top-level keys of `.claude/settings.json`.
- Not implemented: a Gemini CLI `BeforeModel` router (its payload is not known to tell a subagent call from the main session, and a swap in the main session would break its cache); a Kilo and OpenCode `task` router (argument mutation unconfirmed); effort variants on Kilo and OpenCode.
- Differs from decision 0020 (layer 3): the verification stop hook (fact 0023) keeps the agent working and counts attempts against the same bound, but does not itself re-dispatch to a stronger model; the agent asks `go-getter route --escalate` for the next tier, and the hook hands over to a human when the bound is reached. No host's stop hook can start a delegation.
- The coverage report reads component 11 as `hook` on every host because the capability manifests give tier 2 to all seven (fact 0009); in practice Copilot gets no compiled model and Gemini CLI, Kilo and OpenCode no router, so routing there is advisory.
