## Decision

Supersedes 0004 (v0.1 itself is unchanged: foundation plus the agent core packs).

- **v0.2**, in three waves, each wave shippable on its own:
  - **A, cheap and deterministic**: attribution with must-have and nice-to-have refs; plan files that carry a task class per step, dependencies and a guided `go-getter plan next` (0069); a project watcher-noise policy (0070).
  - **B, harness core**: restricted-path access modes with a hook fix and tool-output redaction, the first slice of the sanitization layer (0072); verification checks split into local and CI duties (0071).
  - **C, the original v0.2**: routing calibration (0017), full observability, human-in-the-loop gates, state and checkpointing.
- **v0.3**: SDLC git workflow (branching, commits, PRs; replaces the interim workflow below) and detect-and-tolerate support for spec tools (0075); a spike on compiling guardrails, facts and procedures into runbooks.
- **v0.4**: testing, coverage, debugging; memory beyond the knowledge base. **Later**: execution sandbox, release, review, docs and remaining SDLC packs; the later slices of the sanitization layer.
- **Interim workflow** (carried over from 0004; replaced by the `git-workflow` pack, decision 0099, on 2026-10-10): short-lived `type/slug` branches, PRs, squash merge into protected `main`, Conventional Commits, `Refs:` trailers, one git worktree per parallel task.
- The order after v0.2 is provisional. It was re-evaluated when v0.2.0 shipped and confirmed by the owner (2026-10-10); it is re-evaluated again when v0.3.0 ships.

## Why

The owner proposed eight improvements (2026-10-05). Three are small and deterministic (wave A) and the DLP gap and local/CI split are already known debt of the v0.1 packs (wave B), so they come before calibration, which needs real telemetry anyway. Spec-tool support builds on `go-getter refs` and the git workflow.

## Tradeoffs considered

- **Original v0.2 first, proposals in v0.3**: smaller v0.2, but known DLP debt and cheap wins wait.
- **Security only in v0.2**: sharpest focus, but defers the calibration the routing pack was built for.
- **Cost accepted**: v0.2 is larger than 0004's; the waves cut it into releasable pieces.
